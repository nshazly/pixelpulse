# Security Policy

## Supported Versions

Only the latest release of PixelPulse receives security fixes.

## Reporting a Vulnerability

Please do not open a public issue for security problems.

Report vulnerabilities privately through GitHub: go to the [Security tab](https://github.com/nshazly/pixelpulse/security) and click **Report a vulnerability**. Include steps to reproduce, the affected version, and your macOS version.
